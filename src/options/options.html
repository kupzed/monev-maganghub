🔑 Cara Mendapatkan Google Gemini API Key Gratis

  1. Kunjungi Google AI Studio (aistudio.google.com/apikey).
  2. Login menggunakan akun Google pribadi kamu.
  3. Klik tombol "Create API Key" lalu pilih project baru atau default.
  4. Salin string API Key yang berawalan AIzaSy... dan tempelkan di tab Konfigurasi AI pada ekstensi ini.
  5. Klik "Test Koneksi" lalu simpan. Selesai! Kuota gratis Google AI Studio sangat melimpah untuk kebutuhan laporan harian.

🚀 Cara Menggunakan di Halaman MagangHub Kemnaker

  1. Buka halaman portal Monev MagangHub Kemnaker.
  2. Masuk ke menu Riwayat Laporan dan pilih tanggal yang ingin diisi.
  3. Klik tombol ikon melayang 📝 (FAB) di pojok kanan bawah layar. Tombol ini juga bisa di-drag ke posisi yang kamu inginkan.
  4. Pilih template atau ketik poin singkat kegiatan kamu hari ini.
  5. Klik "Generate & Preview". Periksa hasil dan jumlah karakter (wajib min. 100 karakter).
  6. Klik "Isi ke Form Laporan" untuk otomatis mengisi 3 kolom form (Aktivitas, Pembelajaran, Kendala).
